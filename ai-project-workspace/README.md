# AI Project Management & Developer Workspace

Portfolio-ready React + Node.js workspace combining project management, Kanban planning, developer file navigation, code preview and an AI copilot.

## Run

```bash
cd ai-project-workspace
npm install
npm run dev
```

Optional API:

```bash
npm run server
```

## Stack
- React + Vite
- JavaScript
- Node.js + Express
- REST API
- Responsive custom CSS

This project is intentionally AI-ready: the Express API exposes `/api/ai/plan` and can be connected to an AI provider through environment variables without committing secrets.
