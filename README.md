# AI-Powered CRM & Lead Management SaaS

A portfolio-grade full-stack CRM for managing leads, sales pipelines, follow-ups and AI-assisted outreach.

## Stack
- React + Vite + Tailwind CSS
- Node.js + Express
- PostgreSQL-ready data layer
- JWT authentication
- REST API
- AI service abstraction for lead scoring and email generation

## Features
- Authentication and protected dashboard
- Lead CRUD and search/filtering
- Kanban sales pipeline
- AI lead scoring
- AI-generated cold/follow-up emails
- Analytics dashboard
- Follow-up tracking
- Responsive SaaS UI

## Run
```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` and configure the API/database/AI settings.
